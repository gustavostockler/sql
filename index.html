Como funciona

Cada lição tem uma explicação curta e um desafio. Você escreve a consulta, executa e o sistema confere o resultado.

  1. Módulos (à esquerda). São 15 módulos, do básico ao avançado. Os quadradinhos ao lado de cada módulo mostram quais lições você já concluiu.
  2. Lição (ao centro). Leia a explicação, o desafio e consulte as tabelas disponíveis no pesquisador de objetos.
  3. Editor (à direita). Escreva o SQL e clique em Executar código (ou Ctrl + Enter). O resultado aparece logo abaixo.
  4. Travou? Abra Solução, copie para o editor e execute. Se os dados ficarem bagunçados, use Restaurar banco.

Ao concluir todas as lições de um cenário, o botão Certificado no topo é liberado.
